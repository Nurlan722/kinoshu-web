# KinoShu 🎬

Сайт-каталог для фильмов с двумя способами просмотра: собственные видеофайлы при наличии прав на распространение и ссылки на официальные стриминговые платформы.

## Состав v1.0
- 31 название в категории «Рождественские фильмы»
- Поиск по названию, оригинальному названию и году
- Адаптивные карточки фильмов
- Модальное окно фильма с HTML5-плеером и внешними ссылками
- Неактивная кнопка внутреннего просмотра, если видеофайл не указан
- Витрина готова для Cloudflare Pages / GitHub Pages

## Настройка просмотра
Каталог находится в `app.js` (массив `FILMS`). Поля:
- `poster`: HTTPS-адрес постера, опубликованного с разрешения правообладателя
- `video`: HTTPS-адрес видеофайла, который разрешено распространять (пока пусто)
- `services`: список объектов вида `{"name":"Сервис","url":"https://example.com/legal-title"}`
- `description`: описание, если необходимо

**Важно:** названия и годы первоначально взяты из пользовательского списка. Отдельные названия и соответствие оригинальным фильмам требуют уточнения перед публикацией метаданных. Официальные постеры и ссылки не подставлены автоматически: их нужно проверять по правам и доступности для региона.

## Публикация
Cloudflare Dashboard → Workers & Pages → Create → Pages → Import existing Git repository → `Nurlan722/kinoshu-web`.
Build command: оставить пустым; output directory: `/` (или выбрать корень проекта в соответствующем интерфейсе).
Для этой статической версии не требуются сборка, секреты и сервер.

## Безопасность и будущая админ-панель
В этой версии **нет загрузки видео и админ-панели**. Никогда не размещайте приватные токены, пароли, секретные ссылки или административные API-ключи в `app.js`. Следующий этап: Cloudflare Access/серверная авторизация для администратора, Worker API, R2/Stream, временные подписанные URL, валидация прав и лимиты загрузки. Публикация видео по общедоступному URL возможна только с соответствующим разрешением.
